# 🌸 SRITHI THE COUTURE — Elegant Ethnic Wear

A single-page e-commerce website for **SRITHI THE COUTURE**, exclusively dedicated to premium Indian Sarees and Salwar Suits.

## ✨ Features
- **Curated Collections**: Exclusively Sarees and Salwar Sets with rich product schemas.
- **Dynamic Routing**: Instant hash-based SPA routing with product details, cart, checkout, wishlist, search, and category filters.
- **Offline & CDN Assets**: Studio photography for all products, hero banners, and defensive fallbacks.
- **Indian E-Commerce Ready**: Currency formatted in ₹ (INR), size selector for Salwars, free shipping threshold calculations, and delivery info.
- **Responsive & Elegant UI**: Built with a luxury color palette (Cream, Ivory, Maroon, Gold) and Playfair Display + Lato typography.

## 🚀 Getting Started
Simply open index.html directly in any modern web browser or serve via a lightweight HTTP server:
